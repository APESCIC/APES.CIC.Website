# Complete the next version

Complete the next version of this website, following `.cursor/skills/complete-next-version/SKILL.md` and `.cursor/rules/version-shipping.mdc`:

1. Run the live preview gate (`scripts\preview.ps1`, then open the preview in Cursor's browser).
2. Run `php scripts/milestone-version next` and show its output, including any warnings. Stop if it fails.
3. Create or resume the milestone branch, then work every issue in the milestone on it behind one draft PR.
4. When every issue is committed, follow `.cursor/skills/release-version/SKILL.md` up to the ship-gate question.
